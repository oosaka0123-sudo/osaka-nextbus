# data/ ディレクトリについて

## osaka-citybus-stops.json

アプリが起動時に読み込む「実データ(停留所名・緯度経度)」ファイルです。

```json
[
  { "id": "省略可・省略時は自動生成", "name": "大国町", "lat": 34.6596, "lon": 135.4991 },
  { "name": "天王寺駅前", "lat": 34.6461, "lon": 135.5134 }
]
```

- `name` / `lat` / `lon` は必須。`id` は任意(省略時は名前から自動生成)。
- **現時点ではこのファイルは空配列 `[]` です。** 空、または存在しない場合、アプリは自動的に
  `js/data.js` 内のデモ停留所データにフォールバックします(アプリが壊れることはありません)。
- 行き先(方面)・発車間隔・時刻表はこのファイルには含めません。正式な時刻表データが
  無いため、架空の時刻を本物のように表示しないよう、このファイルに載った停留所は
  画面上「🚧 時刻表データ準備中」と表示され、方面プルダウンは無効化されます
  (偽の発車時刻は一切生成しません)。

### データの出典に関するルール

このファイルに投入するデータは、**合法的に利用可能な公開データのみ**を出典としてください。

- 優先: 国土交通省「国土数値情報(バス停留所データ / P11)」
  https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P11.html
- 大阪シティバス公式サイトや「い・ま・ど・こ？」等のスクレイピングは禁止。
- 非公開API・利用規約違反となるAPIの利用は禁止。

### 実データへの反映手順(概要)

1. 上記の国土数値情報ダウンロードサイトで大阪府のバス停留所データ(GeoJSON形式推奨)を取得する。
2. `scripts/convert-ksj-p11.mjs` を使って、大阪シティバス(大阪市高速電気軌道・Osaka Metro Bus等)
   の事業者に絞り込み、このファイルの形式に変換する。
   使い方は `scripts/convert-ksj-p11.mjs` 冒頭のコメントを参照。
3. 生成された `osaka-citybus-stops.json` をこのディレクトリに配置してコミットする。
